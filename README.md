# Homebrew tap for FuckAds

```sh
brew install PankajKrana/tap/fuck-ads
sudo fuck-ads enable
```

The formula builds [PankajKrana/fuck-ads](https://github.com/PankajKrana/fuck-ads)
from the tagged source. See that repository for what FuckAds does, its privacy
model and the browser extensions.

To remove it: `sudo fuck-ads uninstall --yes`, then `brew uninstall fuck-ads`.
