# Homebrew tap for AdBlock

```sh
brew install PankajKrana/tap/adblock
sudo adblock enable
```

The formula builds [PankajKrana/dnsward](https://github.com/PankajKrana/dnsward)
from the tagged source. See that repository for what AdBlock does, its privacy
model and the browser extensions.

To remove it: `sudo adblock uninstall --yes`, then `brew uninstall adblock`.
